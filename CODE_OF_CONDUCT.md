# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Its full text applies here.

## Our pledge, in short

- Be kind. Assume the other person means well.
- Critique the code and design, never the person.
- No harassment, insults, sexual attention, or publishing of anyone's private
  information.
- Everyone is welcome regardless of background, identity, or experience level.

This applies across issues, pull requests, code reviews, and anywhere else the
project is represented.

## Reporting

Report behaviour that breaks this code using GitHub's report tools (`...` menu
on the comment, issue, or pull request → **Report content**).

⚠ There is no separate private contact email for this project yet.

One person maintains this project in spare time, so replies may take a while.
Reports are handled privately. The maintainer may edit or remove content and
block repeat offenders.
